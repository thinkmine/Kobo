# Write and validate Kobo applications

## Language version 0.1.47

1. Read [the AI coding guide](../../../KOBO-AI-CODING-GUIDE.md) and its links
   to the language specification before writing Kobo.
2. Choose a script, multi-file application, or .NET project according to
   the request; use documented Kobo syntax.
3. Implement the whole requested behavior using real Kobo constructs and
   available .NET dependencies. Handle input and external errors explicitly.
4. Validate the example or application and report limitations honestly.
