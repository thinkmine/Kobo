# Advanced Variables


## Lambdas
Lambdas can be defined in kobo using a representation of the lambda signature as shows below

```kobo

//lambdas
var:()->void var18 = null
var:()->int var19 = null
var:(int)->int var20 = null

//explicit declaration of a lambda function
//a void lambda cannot return a value - uncomment this to see the error
var:(string)->void lambda_3 = (x) =>
{
    Console.WriteLine("void lambda 2")
}

var:(string)->int lambda_4 = (x) =>
{
    return 77
}

```

Lambdas can also participate in type inference like other variables

```kobo

//type inference for lambda function
var lamdba1 = () =>
{
    return 77
}

//type inference void lambda function
var lambda_2 = ()=>
{
    Console.WriteLine("void lambda 2")
}

```

## First class json

In kobo, json is a first class citizen.  You can define in in code without wrapping it in a string or anything of the sort.
json values can also reference anything that is in scope of the local context where the variable is being declared.  In the sample
below _n_ is an int variable that is being passed as the value of ```type``` in the json declaration

```kobo


var n = 9

//Native json
var:json information =
{
    "type": n,
    "data":[
        "one",
        "two",
        "three",
    ],
    "contact":{
        "address":"1234 street",
        "phone": "3334445555"
    }
}

```

The properties of the json object can be read using natural propery syntax.  We are reading the type, reading the data array as an array
and drillign into the contact object to pull out the address field!

```kobo

//json properties read with natural syntax
Console.WriteLine(information.type)
Console.WriteLine(information.data[1])
Console.WriteLine(information.contact.address)

```

You can also use this same approach to update any values in the json as needed!

```kobo

//and updated the same way
information.type = "rock"
information.contact.address = "99 avenue"

```

Finally, you can quickly and easily convert from json to a string and back both implicitly and explicityly through the StringValue property

```kobo

//StringValue returns JSON text; assignment parses JSON text implicitly
var:string json_text = information.StringValue
var:json reloaded = json_text
Console.WriteLine(reloaded.contact.address)



Console.WriteLine("Sample Complete")
```
