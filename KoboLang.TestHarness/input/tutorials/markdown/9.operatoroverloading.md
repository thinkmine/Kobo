# Operator Overloading
**Operator overloading in Kobo** allows developers to define how standard operators, 
such as `+`, `-`, `*`, `/`, and comparison operators, behave when applied to custom types.
 By associating operators with user-defined implementations, Kobo enables objects to 
 participate in natural, expressive operations without requiring explicit method calls. 
 This is particularly useful for mathematical types, domain-specific models, and value 
 objects where operators have intuitive meanings. Operator overloading improves readability 
 while preserving strong typing and compile-time validation, allowing custom types to 
 behave consistently with built-in types. As a .NET-oriented language, Kobo can translate 
 supported operator definitions into their corresponding C# operator implementations.

 Lets assume the same PersonInterface class hiearchy from previous samples on types in kobo

```kobo

[public]
delegate:(int x)->void SampleHandler

//declare an interface
interface:PersonInterface
{
    function:string GetJob()
}

[public, abstract]
class:PersonBase is PersonInterface
{
    [protected, internal]
    var:string _job = "No Job"
    
    [public,virtual]
    function:string GetJob()
    {
        return _job
    }
}

```

We can overload some operators to make it easy to either convert from something else
to a Lawyer, or to combine Lawyer object.  Operator overloading uses the ```operator``` 
keyword instead of ```function``` to encapsulate the bahavior of the overload.

```kobo

[public] 
class:Lawyer is PersonBase
{

    [public]
    event:SampleHandler JobRequested

    [public]
    new(string job)
    {
        parent._job = job
    }

    [public,override] 
    function:string GetJob()
    {
        JobRequested?.Invoke(6)
        return _job
    }

```

This is how to define the + operator overload.  operator routines should encapsulate
everything needed to perform the task.  In this case we are simply concatenating the 
job fields for each part of the expressio.

```kobo

    [public] 
    operator:Lawyer +(Lawyer a, PersonBase b)
    {
        return new Lawyer("${a._job} and ${b._job}")
    }

```

You can also overload the = sign (this is the one used for assignment).

```kobo
    [public] 
    operator:Lawyer =(string str)
    {
        return new Lawyer(str)
    }

```

Finally you can overload the cast operation

```kobo
    [public] 
    operator:Lawyer cast(int i)
    {
        return new Lawyer(i.ToString())
    }
}

```

Now that we have our overloads set we can use them in the language as follows:

```kobo

var:Lawyer john = "I am a lawyer"
var:Lawyer david = (Lawyer)9

var result = david + john
Print(result);
```
