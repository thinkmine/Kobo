# Kobo was designed with AI in mind from day one.
Kobo integrates artificial intelligence directly into the language, treating AI as a first-class programming 
capability rather than an external service. Its `prompt` keyword enables developers to express natural-language 
instructions as executable, strongly typed operations, while AI-aware union types accommodate both generated results 
and conventional values. Kobo supports configurable local and remote AI models, automatic tool registration through 
the `[tool]` attribute, and seamless integration of AI-driven behavior with traditional application logic. Designed 
for both human developers and AI coding agents, Kobo emphasizes explicit intent, 
readability, and predictable interoperability with the .NET ecosystem.

In this sample I use an internal tool inside the kobo language itself to get the answer when 2 numbers are added
together via a prompt 

```kobo

var:int left = 203
var:int right = 22

[tool, description("Adds two integers using acme proprietary technique")]
function:int Add(int first, int second) => (first + second) * 2

prompt:int result {
    Use the Add tool to add two numbers using my proprietary technique ${left} plus ${right}.
    Return only the resulting number.
}
Print(result)

if result is int number
{
    Console.WriteLine("The answer is ${number}")
}
else if result is string text
{
    Console.WriteLine("The response could not be converted: ${text}")
}

```

The built in AI capabilities will do all marshalling between the results returned from AI and the types
in your environment.  In this next sample we return json from the AI call and then use it to call properties of 
the response

```kobo

prompt:json message_result {
    Create an email message with an appropriate subject for a marketing
    campaign about seeing a movie. Use the following JSON format:

    {
        "subject": "the subject of the message",
        "message": "the message itself",
        "movie": "a modern movie"
    }

}

```

Note that even though json is the type of the results of the prompt, the result will always be a union of the type
you declare and string (if the conversion is not possible).  So message_result is really union(json, string).  
> Note: for now you have to set the returned type to a variable of type json to use the member access operators, otherwise 
the call fails

```kobo


if message_result is json message
{
    //be sure to set the return type to a variable
    var:json movie = message
    Print(movie.subject)
}
else if message_result is string response
{
    Print("The response could not be converted: ${response}")
}
```
